# TermiArt
C program to convert files with numbers from 0-8 into pixels in the terminal.

# Use

Compile:
`gcc TermiArt.c -o TermiArt`

execute:
  `./TermiArt sourceFile`
or just enter the file name manually when prompted for source.

`./TermiArt`
`Enter source: sourceFile`

# Example content:
```
123454323456543234565432
623363251364
523
465246334574635423532
```
